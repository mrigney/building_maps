# Demo Output - Urban Terrain Generator

This directory contains sample output generated by the Urban Terrain Generator to demonstrate the output format and structure.

## What's Included

This demo contains a 5x5 grid of synthetic buildings (25 buildings total) to show you what the output looks like.

### Files

- **models/** - Directory containing individual building models (25 GLB files)
  - `demo_0_0.glb` through `demo_4_4.glb`
  - Each file is ~1.1 KB
  - Total: ~27.5 KB

- **manifest.json** - Master index file (4.5 KB)
  - Contains metadata about all buildings
  - Building locations (lat/lon)
  - Building properties (height, type, area)
  - Coordinate system definition

- **material_mapping.json** - Material group assignments (750 bytes)
  - Groups buildings by material type (concrete, brick)
  - For applying thermal properties in your solver

- **combined_scene.glb** - All buildings in a single file (6.6 KB)
  - Useful for quick visualization
  - Can be opened in 3D viewers like Blender or online GLB viewers

## Viewing the Models

### Option 1: Online GLB Viewer
1. Go to https://gltf-viewer.donmccurdy.com/
2. Drag and drop any `.glb` file from the `models/` directory
3. Or drag `combined_scene.glb` to see all buildings at once

### Option 2: Blender
1. Open Blender
2. File → Import → glTF 2.0 (.glb/.gltf)
3. Select a building file or the combined scene

### Option 3: VS Code with glTF Tools
1. Install the "glTF Tools" extension in VS Code
2. Right-click on a `.glb` file
3. Select "View in 3D"

## Understanding the Data

```
Origin: (40.758°N, 73.9689°W)
+X axis: East (meters)
+Y axis: North (meters)
+Z axis: Up (meters/height)
```

The buildings are arranged in a 5x5 grid:
- 50 meters spacing between buildings
- Building dimensions: 15-30m wide × 20-40m long
- Building heights: 10-50m tall
- Building types alternate: residential, commercial, industrial

### Material Groups
- **Concrete** (15 buildings): Commercial and industrial buildings
- **Brick** (10 buildings): Residential buildings

## Using This Data

### Example: Loading in Python

```python
import json
import trimesh

# Load the manifest
with open('manifest.json', 'r') as f:
    manifest = json.load(f)

# Get coordinate system info
origin_lat = manifest['metadata']['coordinate_system']['origin_lat']
origin_lon = manifest['metadata']['coordinate_system']['origin_lon']

# Load a specific building
building_id = 'demo_0_0'
building_info = manifest['buildings'][building_id]
model_file = f"models/{building_info['model_file']}"

# Load the 3D mesh
mesh = trimesh.load(model_file)

print(f"Building: {building_id}")
print(f"Height: {building_info['properties']['height_m']:.1f}m")
print(f"Type: {building_info['properties']['building_type']}")
print(f"Vertices: {len(mesh.vertices)}")
print(f"Faces: {len(mesh.faces)}")
```

### Example: Applying Thermal Properties

```python
# Load material mapping
with open('material_mapping.json', 'r') as f:
    materials = json.load(f)

# Your material database
thermal_properties = {
    'concrete': {
        'conductivity': 1.4,  # W/m-K
        'emissivity': 0.9
    },
    'brick': {
        'conductivity': 0.6,  # W/m-K
        'emissivity': 0.85
    }
}

# Assign properties to buildings
for material_type, building_ids in materials['groups'].items():
    props = thermal_properties[material_type]
    for building_id in building_ids:
        # Apply properties to your simulation
        print(f"{building_id}: {material_type} - {props}")
```

## File Format Details

### GLB Format
- Binary glTF 2.0 format
- Self-contained (geometry + optional materials in one file)
- Widely supported
- Good for visualization and general use

### Manifest Structure
```json
{
  "metadata": {
    "generated": "timestamp",
    "coordinate_system": {...},
    "bounding_box": {...}
  },
  "statistics": {...},
  "buildings": {
    "building_id": {
      "model_file": "filename.glb",
      "position": {"lat": ..., "lon": ...},
      "properties": {"height_m": ..., "building_type": ..., "area_sqm": ...}
    }
  }
}
```
